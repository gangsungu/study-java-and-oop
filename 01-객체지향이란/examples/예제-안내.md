# 객체 지향 실습 예제

[객체 지향이란 정리](../객체지향이란.md)의 각 섹션에 대응하는 **실행 가능한** 자바 예제입니다.
문서를 읽다가 "그래서 실제로 어떻게 되는데?" 싶은 지점을 직접 돌려보며 확인하세요.

## 실행 방법

Java 11+ 부터는 컴파일 없이 `.java` 파일을 바로 실행할 수 있습니다.

```bash
java 01-객체지향이란/examples/Ex01_OopBasics.java
```

> **Windows에서 한글이 깨진다면** 인코딩 옵션을 붙이세요.
> ```bash
> java -Dstdout.encoding=UTF-8 01-객체지향이란/examples/Ex01_OopBasics.java
> ```
> 또는 터미널에서 `chcp 65001` 을 먼저 실행합니다.

## 일부러 실패하는 예제 (`errors/`)

문서에 "**컴파일 에러** 발생"이라고 적힌 상황을 실제 에러 메시지로 확인하는 파일들입니다.
**실행이 아니라 컴파일**만 해보세요.

```bash
javac 01-객체지향이란/examples/errors/Err01_MissingSuper.java
```

| 파일 | 재현하는 에러 |
|------|-------------|
| [errors/Err01_MissingSuper.java](errors/Err01_MissingSuper.java) | `constructor Animal in class Animal cannot be applied to given types` — 부모에 인자 없는 생성자가 없는데 자식이 `super`를 생략 |
| [errors/Err02_DefaultConflict.java](errors/Err02_DefaultConflict.java) | `class Duck inherits unrelated defaults for move()` — 두 인터페이스의 `default` 메서드 충돌 |
| [errors/Err03_AbstractRules.java](errors/Err03_AbstractRules.java) | `Animal is abstract; cannot be instantiated` / `Cat is not abstract and does not override abstract method speak()` |

각 파일 하단 주석에 해결 방법이 적혀 있습니다. 직접 고쳐서 컴파일이 통과하는지 확인해 보세요.

## 추천 학습 순서

1. `Ex01` 실행 → 4대 특징이 어떻게 협력하는지 감 잡기
2. `errors/Err01` 컴파일 → 에러를 본 뒤 `Ex02` 실행 → 생성자 규칙 확정
3. `Ex03` 실행 → **"부를 수 있는가는 선언 타입, 어떻게 동작하는가는 실제 객체"** 한 문장으로 정리
4. `errors/Err02`, `errors/Err03` 컴파일 → `Ex04` 실행 → is-a / can-do 기준 세우기
