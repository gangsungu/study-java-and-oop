## 폴더 구조 규칙

새 주제는 **폴더 하나 추가**로 끝납니다.

```
NN-주제이름/
├── 주제이름.md      ← 정리 본문
├── 연습문제.md      ← 주관식 문제 + 접힌 정답
└── examples/       ← 실행 가능한 예제
    ├── 예제-안내.md   ← 예제 목록·실행 방법
    ├── ExNN_....java
    └── errors/     ← 일부러 컴파일에 실패시켜 에러 메시지를 확인하는 예제
```

- **번호는 재사용하지도, 다시 매기지도 않는다.** 중간에 배운 주제가 생겨도 맨 뒤에 새 번호로 붙이고, 읽는 순서는 위 목차에서만 조정한다. 그래야 폴더 경로와 링크가 영원히 안 깨진다.
- **`README.md`라는 이름은 레포 루트에만 쓴다.** 파일 이름만 보고 무슨 문서인지 알 수 있어야 한다. 주제마다 `README.md`가 생기면 에디터 탭에서 구분이 안 된다.
- **파일명에 공백을 쓰지 않는다.** 마크다운 링크가 `%20`으로 지저분해지고 터미널에서 매번 따옴표를 씌워야 한다.
- 예제 파일 이름은 **정리 문서의 섹션 순서와 맞춘다.** (`Ex02_ConstructorRules` ↔ "상속과 생성자 규칙")

## 예제 실행

Java 11+ 부터는 컴파일 없이 `.java` 파일을 바로 실행할 수 있습니다. **레포 루트에서** 실행하세요.

```bash
java 01-객체지향이란/examples/Ex01_OopBasics.java
```

`errors/` 안의 파일은 실행이 아니라 **컴파일**만 해서 에러 메시지를 확인합니다.

```bash
javac 01-객체지향이란/examples/errors/Err01_MissingSuper.java
```

> Windows 터미널에서 한글이 깨지면 `java -Dstdout.encoding=UTF-8 ...` 을 쓰거나 `chcp 65001` 을 먼저 실행하세요.
